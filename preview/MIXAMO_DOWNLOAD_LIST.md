# What to download from Mixamo (mixamo.com, your Adobe login)

Mixamo animations made for the SAME character share one rig, so they drop straight into the kit.
Download each file as **FBX**, **30 fps**. For animations, tick **In Place** whenever Mixamo offers it.
The kit loads FBX files directly; you don't need to convert them.

## 1. Characters (6–8 people): Format FBX, Pose T-pose, "With Skin"
Choose realistic, everyday-looking people in casual clothes, and mix:
- 2 young adults (one woman, one man)
- 2 middle-aged adults
- 1 older person
- 1 child or teen, if available
- 1–2 workers (waiter or barista apron, office clothes)

## 2. Animations: "Without Skin", applied to ONE of your characters (Mixamo retargets per character)
Search for these names (or the closest match) in Mixamo:

| Purpose | Search terms |
|---|---|
| walking | Walking, Slow Walking, Old Man Walk, Female Walk |
| running | Running, Jogging |
| standing | Standing Idle, Breathing Idle, Looking Around, Waiting |
| talking | Talking, Standing Talking (×2 variants), Arguing |
| sitting | Sitting Idle, Sitting Talking, Sitting Laughing, Stand Up (from chair), Sit Down |
| café | Drinking (seated), Typing, Texting / Using Phone |
| reactions | Waving, Pointing, Shrugging, Head Nod Yes, Shaking Head No |
| emotion | Sad Idle, Crying, Hug, Kneeling, Praying |
| actions | Picking Up, Reaching Out, Catching, Carrying, Pushing |
| falls | Tripping, Falling Down, Getting Up |
| turns | Turn 180, Left Turn, Right Turn |

## 3. Send them to me
Zip everything (characters plus animations) and attach the zip here. Keep Mixamo's file names.
